code-simplification 스킬을 호출합니다.

최근 변경된 코드(또는 지정된 범위)를 정확한 동작을 보존하면서 단순화합니다:

1. CLAUDE.md를 읽고 프로젝트 컨벤션을 파악합니다
2. 대상 코드를 식별합니다 — 더 넓은 범위가 지정되지 않는 한 최근 변경분을 대상으로 합니다
3. 손대기 전에 코드의 목적, 호출자, 엣지 케이스, 테스트 커버리지를 이해합니다
4. 단순화 기회를 스캔합니다:
   - 깊은 중첩 → 가드 절 또는 헬퍼 추출
   - 긴 함수 → 책임별로 분리
   - 중첩된 삼항 연산자 → if/else 또는 switch
   - 일반적인 이름 → 설명적인 이름
   - 중복된 로직 → 공용 함수
   - 죽은 코드 → 확인 후 제거
5. 각 단순화를 점진적으로 적용 — 변경할 때마다 테스트를 실행합니다
6. 모든 테스트가 통과하고, 빌드가 성공하며, diff가 깔끔한지 확인합니다

단순화 후 테스트가 실패하면 해당 변경을 되돌리고 재검토합니다. 결과를 리뷰하려면 `code-review-and-quality`를 사용합니다.
