test-principal 스킬을 호출합니다.

새 기능의 경우:
1. 기대 동작을 기술하는 테스트를 작성합니다 (실패해야 함)
2. 테스트를 통과시키는 코드를 구현합니다
3. 테스트를 초록(green)으로 유지하면서 리팩터링합니다

버그 수정(Prove-It 패턴)의 경우:
1. 버그를 재현하는 테스트를 작성합니다 (반드시 실패해야 함)
2. 테스트가 실패하는지 확인합니다
3. 수정 사항을 구현합니다
4. 테스트가 통과하는지 확인합니다
5. 회귀 확인을 위해 전체 테스트 스위트를 실행합니다

브라우저 관련 문제의 경우, Chrome DevTools MCP로 검증하기 위해 browser-testing-with-devtools도 호출합니다.
